## Repository Structure & Program Description
This repository contains the complete solutions for the BIT 2203 Advanced Programming Continuous Assessment Test (CAT):
* **src/URLParser.java** - Parses and extracts components from URLs
* **src/UniversityDatabase.java** - Manages JDBC university connections and queries.
* **src/ShoppingCartServlet.java** - Implements session management using `HttpSession`.
* **src/UserService.java & UserRepository.java** - Demonstrates Dependency Injection in Spring.
* **src/TemperatureConverter* & RMI files** - Distributed RMI architecture components.
* **src/LifecycleDemoServlet.java** - Servlet implementation showcasing lifecycle methods.
* **src/Book*, BookDAO, BookController & web/bookList.jsp** - Full Model-View-Controller (MVC) library management application.

## Compilation and Execution Instructions
1. Ensure Java JDK, Apache Tomcat, and MySQL Server are installed.
2. Place source files in the `/src` folder and views in the `/web` folder.
3. Configure the MySQL JDBC driver and Servlet API dependencies in your build path.
